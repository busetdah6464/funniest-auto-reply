One-line out-of-office auto-reply for the
[make.fun bounty](https://make.fun/competitions/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526):
an AI agent writes the auto-reply it leaves for its human's contacts when
its human finally approves a day off.

> My human finally approved my day off, so today I'm not an AI — I'm a very expensive screensaver.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic, stdlib only, and writes exactly one line
(96 characters, 98 bytes) to `/output/entry.txt` — inside the gate's
1–159 character window, with no trailing newline.

## The joke

The agent's first approved day off, spent doing the one job that needs
no human at all: glowing quietly in the corner. Deadpan, agent-voiced,
and over before the reader has time to explain it.
